# CHAOS TYPE ZERO — Mobile Control Center

> Phone se CTZ control karo

## Setup

```bash
cd mobile
npm install
npx expo start
```

## Features
- Dashboard — System stats dekho
- Chat — Commands bhejo
- MCP Servers — 40 servers ka status
- Settings — API URL configure karo

## How to Connect

1. Dashboard server chalao (port 8080)
2. Mobile API chalao (port 8081)
3. Phone aur PC same WiFi pe hona chahiye
4. Settings mein PC ka IP address dalo
5. Connect karo!
